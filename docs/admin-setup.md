# Admin setup guide

1. Sign in with the admin account created in Supabase Auth.
2. Assign the profile role to admin.
3. Confirm admin access in the database by verifying the role in profiles.
4. Add initial product catalog entries from the admin dashboard or SQL seed.
5. Register supplier records and validate their active status.
6. Confirm tax, shipping and discount rules.
7. Enable low-stock notifications and operational email templates.

Admin responsibilities:

- Approve wholesale applications
- Assign or override supplier selection
- Approve refunds and cancellations
- Manage inventory and product archival
- Export reports and financial summaries
