# Supplier setup guide

1. Create supplier profiles in Supabase Auth.
2. Assign role to supplier and validate record in profiles.
3. Add supplier address and coverage metadata.
4. Set product categories and pricing limits.
5. Confirm active status and assigned capacity.
6. Review assigned orders from the supplier dashboard.
7. Accept, reject or reassign orders only within the order lifecycle defined by the admin.

Supplier access policy: suppliers can only view orders assigned to their own supplier id and may not access other suppliers’ data or admin dashboards.
